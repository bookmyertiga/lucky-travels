# Lucky Travels SEO implementation

This project is configured for `https://gobengaluru.in` and focuses exclusively on Premium Ertiga services.

## Included

- Unique metadata and canonical URLs
- Open Graph and Twitter metadata
- Dynamic `/sitemap.xml`
- Dynamic `/robots.txt`
- LocalBusiness, TaxiService, WebSite, Service and FAQ structured data
- Eight service landing pages
- Fifteen Bengaluru locality landing pages
- Internal links in navigation, content and footer
- Mobile-first call and WhatsApp actions
- Descriptive image alt text

## Before launch

1. Add the final Google Maps / Google Business Profile URL when available.
2. Replace any placeholder vehicle or interior images with final owned images if desired.
3. Verify the deployed domain in Google Search Console.
4. Submit `https://gobengaluru.in/sitemap.xml`.
5. Add real customer reviews only after receiving permission and use exact, verifiable wording.
6. Add analytics only after choosing the preferred analytics platform and privacy approach.

Do not create repetitive doorway pages. Each future location page should contain genuinely useful, locality-specific information.
